# Doro 懸浮聊天窗計畫

2026-10-07；基準 c586a89，沿用 codex/quiet-companion-grounding。

## 目標

不用進入 Chat 子選單即可跟 Doro 連續聊天。使用與粉紅髮色相配的淡粉底、玫瑰粉按鈕與深莓色文字，保持可讀性。

## 互動與細節

- 啟動時在 Doro 附近顯示可拖曳的「聊聊」小浮鈕，不搶鍵盤焦點；點擊展開非模態、置頂的聊天窗。展開後可拖動標題列，收起後仍有直接入口。
- 對話窗有訊息紀錄、狀態提示、多行輸入與送出按鈕；Enter 送出、Shift+Enter 換行。中文輸入法組字中的 Enter 不誤送。訊息以純文字顯示，不執行 HTML。
- 送出後不關閉視窗；沿用現有聊天、人設、模型與網頁操作流程，不另建模型連線。失敗／忙碌拒收保留草稿，網頁操作中的確認與取消仍可送出。
- 顯示本次啟動期間送出的訊息與 Doro 的泡泡回覆；處理中的文字放在狀態區。限制顯示紀錄長度，不額外將聊天內容存檔。現有清除聊天紀錄入口同步清除畫面。
- 關閉按鈕／Esc 收起，保留草稿與紀錄；回覆不自動展開或搶焦點。展開或輸入時取消背景陪伴動作，視窗展開期間暫停自主散步與回休息點。
- 視窗初始位置和展開位置限制在螢幕可用區域；獨立於角色視窗，不改動角色腳底或泡泡版面。
- 原 Ask Doro 入口改為開同一個懸浮窗，另在右鍵最上層提供中文入口。

## 驗收

Qt 測試涵蓋非模態重用、收起與草稿、輸入法及快捷鍵、送出成功／拒收／同步回覆順序、回覆與處理狀態、忙碌時不走動、位置邊界及清除紀錄。離屏渲染查看配色與版面，再跑完整測試、Ruff、Black、repo_map、diff 檢查，更新文件與原 PR。真實 Windows 輸入法、混合 DPI 及置頂行為另列實機驗收限制。

## 完成紀錄

以上已實作。預設僅顯示 142 × 64 的浮鈕視窗，展開為 410 × 520 邏輯像素；淡粉底、玫瑰粉按鈕、深莓色文字。浮鈕從角色本體旁邊起始，右側空間不足時改放左側，再限制在螢幕內。位置只保留於本次執行，不新增位置設定。

聊天以 CoreManager 回傳既有 orchestrator 的接受／拒收結果；拒收不清空輸入。同步的本機回覆仍排在使用者訊息之後。非自動請求失敗時，只在輸入框空白的情況下恢復上一句，避免蓋掉正在寫的新草稿。回覆沿用泡泡事件，處理文字放在獨立狀態區；工作完成會清掉等待提示。最多保留 200 則顯示紀錄，包含 Doro 本機台詞等泡泡回覆，不額外存檔。
