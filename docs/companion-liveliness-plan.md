# Doro 活潑陪伴實作計畫

狀態：2026-10-06 已實作並完成自動驗證。這份計畫先於程式修改建立；基準提交 cced513，分支 codex/quiet-companion-grounding。

## 目標與既定決策

讓 Doro 有自己的小動作與散步節奏，點她時有立即回應，工作時又能留在自由休息點陪伴。沿用現有 GIF，不要求使用者先提供新素材；底部互動、重力與落地輕蹲維持停用。休息點保存水平與高度，不強制貼底。

本計畫取代舊「桌邊互動」計畫中的產品方向。已完成的幾何、安靜模式與自由休息點保留；舊文中的底部互動不再實作。自動讀取全域鍵盤、視窗內容、滑鼠穿透與獨立泡泡視窗不列入本次：這次以使用者可直接控制的模式與尺寸降低干擾，不擴大系統權限。

## 1. 活潑節奏與短程散步

- 提供「活潑／適中／悠閒」三種節奏，預設活潑，設定可保存。
- 活潑模式約 18–35 秒嘗試一次；適中 40–75 秒；悠閒 90–150 秒。與 Doro 互動後至少留 8 秒空檔。
- 散步改為短程、選擇螢幕內可走的方向，避免對著邊界一直走。不同節奏採不同散步距離。
- 自主動作不連續選同一類；台詞避免連續重複，並設至少 90 秒的發話間隔。優先使用既有本機台詞，不為小動作呼叫模型。
- 姿勢變化使用短暫 Action，結束後恢復原姿勢；取消時不留下計時器回呼把新狀態蓋掉。

## 2. 不搶操作的生命感

- 新增不改變視窗座標的短暫伸展／左右晃動效果；不依賴新 GIF。
- 安靜模式下僅允許低頻、原地且無文字的小動作，拖曳、聊天、動作、轉場時不播放。
- 提供小動作開關。關閉後立即清除效果；安靜模式仍不自主散步或說話。
- 模型回覆、手動選姿勢、拖曳與點擊優先於自主 Action；僅取消自主流程，不取消使用者工作。

## 3. 點擊回應

- 點一下顯示短暫愛心回應，帶輕微的原地動態，與現有點擊 GIF 相容。
- 限制觸發頻率，不排隊累積、不新增聊天泡泡；拖曳不觸發。
- 特效留在既有繪製區，保持腳底與點擊區域穩定；小動作開關也控制這些裝飾效果。

## 4. 設定與素材校正

- 右鍵加入「陪伴設定…」，集中調整活潑程度、小動作、休息姿勢，避免靠「先切 States 再儲存」才能設定。
- 可從現有非移動狀態選休息 GIF，並提供匯入 GIF 建立休息狀態的入口；顯示預覽，取消不改設定。
- 提供目前 GIF 的腳底校正：預覽圖加水平線，使用比例保存，重新載入同一素材可恢復，也能還原自動估計。校正只影響素材接觸邊界，不重新啟用落地。
- 資料錯誤、素材刪除、沒有可用 GIF 時提供明確回退；保留原有其他設定。

## 5. 驗收與交付

- 測試節奏、發話冷卻、不重複、邊緣可走方向、自主 Action 被新互動打斷、安靜原地效果、特效停用、設定重載及素材校正。
- 使用實際 Qt 視窗確認中央／左右邊界、不同 GIF 尺寸及泡泡變化時腳底穩定；離屏檢查新設定介面與效果。
- 跑完整測試、CI 範圍 Black／Ruff、repo_map 與 diff 檢查；更新 README、本計畫結果及原 PR，推到既有分支。
- 不將離屏檢查稱為使用者實機驗收；混合 DPI、工作列變動與實際素材觀感需在交付時清楚列出限制。

## 完成紀錄與操作方式

上述五部分已完成。右鍵「陪伴設定…」集中提供活動節奏、小動作開關、休息姿勢預覽及 GIF 匯入；有正在顯示的 GIF 時，另有「腳底校正」分頁。新匯入的 GIF 以獨立休息狀態保存，取消不修改資料，匯入失敗不留下空白狀態。

自主動作可被點擊、拖曳、開啟選單或聊天打斷。ActionDispatcher 增加保留佇列的取消選项及取消清理回呼；先停止自己擁有的移動、再恢復姿勢和開始後續使用者動作，避免取消背景散步時順便丟掉聊天工作。短暫姿勢的過期回呼不能覆蓋後來選擇的姿勢。

## 保留的限制

- 「伸展」與愛心使用原地繪製效果，沒有製作新角色 GIF；更豐富的肢體演出仍取決於使用者現有素材。
- 腳底校正以完整檔案路徑保存。移動、重新匯入或同路徑更換素材後，可能需要重新校正。它是水平接觸線，無法替浮空素材補出地面或辨認真正腳掌。
- 不讀取作業系統的打字或工作狀態；做其他事情時是否要安靜仍由使用者控制。
- 實際多螢幕／混合 DPI／工作列自動隱藏仍需使用者桌面驗收。此處的通過紀錄不代表已覆蓋這些實機組合。
