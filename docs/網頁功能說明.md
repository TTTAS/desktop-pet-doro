# doro 網頁功能說明（讀 / 查證 / 操作）

> 這份是「我到底加了什麼、怎麼用、為什麼這樣設計」的紀錄。之後忘了就看這裡。
> 對應程式在 `doro_app/core/web/`；功能地圖在 `CLAUDE.md` 的「🌐 網頁」段。

---

## 一句話

讓 doro 會用**牠自己的瀏覽器**幫你做三件事：**讀網頁、上網查證、操作網頁**；卡住或被擋會**誠實說**，危險動作會**先問你**。

---

## 三種能力 + 怎麼用

你**用白話講就好**，doro 會自己判斷要走哪條（不用背指令）。

### 1. 讀 📖
- 「幫我讀這頁 `<網址>`」「這頁在說什麼」「摘要這篇」
- 也可以讀 **doro 自己剛剛打開的那頁**：「讀你剛剛開的網頁」（不用給網址）
- doro 開瀏覽器讀內容 → 交給 AI 摘要／回答。

### 2. 查證 / 找資料 🔎
- 「幫我找 DORO 周邊」「幫我查藍牙耳機推薦」「X 是真的嗎」「幫我查證 X」
- doro 會：**用 Bing 搜尋 → 抓前幾個真正的來源 → 各讀一頁 → 一起比對** → 誠實回報（找不到就說找不到）。
- **只讀不動、最安全**，不需要開任何開關。

### 3. 操作 🕹️（要先開總開關）
- 「幫我在蝦皮把 X 加入購物車」「幫我在某站填表單送出」這種**真的要動手做事**。
- doro 開瀏覽器一步步做；**送出／購買／刪除／登入送出前會先問你**。
- **要先在右鍵選單打開「讓 Doro 操作網頁」**（預設關）。

### 附：登入助手 🔑
- 「幫我開蝦皮我要登入」→ doro 只把站開著、停著讓**你本人**登入（帳密你自己打，doro 不碰），登入狀態會記住，之後操作那站比較不會被擋。

### 附：點桌面 / 瀏覽器按鈕（走另一套：a11y）
- 「幫我點書籤」這種點**電腦畫面上**的東西，走的是 a11y + 滑鼠自動化（不是網頁操作）。
- 需要先開右鍵選單的「讓 Doro 看畫面」＋「讓 Doro 幫忙點滑鼠」。

---

## doro 怎麼決定走哪條？

**交給 AI 判斷**（不是關鍵字硬比對）。AI 會在回覆裡吐一個「暗號」，doro 看到就去做：

| 暗號 | 意思 |
|---|---|
| `[read:網址]` | 讀某頁 |
| `[verify:問題]` | 查證／找資料／比對來源 |
| `[operate:目標]` | 在網站上實際操作辦事 |
| `[login:網址]` | 開站讓你自己登入 |
| `[mouse:click]`（配 `[MOVE:to]`）| 點桌面／瀏覽器工具列（a11y） |

判斷原則（寫在 `dia_prompt.txt`）：**「想知道／找／查」→ 查證；「要在網站上做動作」→ 操作；點「電腦畫面上的東西」→ a11y。**

## 安全與韌性（重點）

- **操作總開關**：右鍵選單「讓 Doro 操作網頁」，預設**關**。關著時叫它操作 → 回「操作功能現在關著喔」。（讀、查證不受此限。）
- **送出前確認**：點到「送出／購買／刪除／登入…」按鈕、或在**結帳/付款/登入頁**按 Enter → **先問你，回「好」才做**。一般頁按 Enter（搜尋那種）不問。
- **喊停**：操作中打「停／取消」中止；關掉瀏覽器視窗也會停；一次最多 12 步。
- **卡驗證碼 / 登入牆**：doro **不代解驗證碼、不繞過偵測**；改成**暫停等你在視窗裡自己處理，完成回「好」就接著做同一個任務**（回「不要」放棄）。
- **防打轉**：一直重開同一頁／點同一顆 → doro 先提醒 AI 換做法，真的還卡住才停。
- **視窗被關**：你手動關掉瀏覽器，doro 會偵測到、老實說一聲，**下次自動重開一個**。
- **誠實不謊報**：撞到登入頁／錯誤頁／沒結果，doro 會說「沒成功／找不到」，不會假裝做好了。
- **跟 a11y 隔離**：操作/查證的提示只給網頁自己的元件，不摻 a11y 的畫面樹。

## 設定與開關

- **右鍵選單**：「讓 Doro 操作網頁」（操作總開關）、「讓 Doro 看畫面」「讓 Doro 幫忙點滑鼠」（a11y/滑鼠，點桌面用）。
- **Max tokens**：右鍵 → Chat → API Settings 裡可調（一次回覆的字數上限，預設 512；長回答調大一點）。
- **真 Chrome**：doro 優先用你電腦裡真正的 Chrome（相容性較好）；沒有就自動退回內建 Chromium。
- **除錯輸出**：用 `run_doro_debug.bat` 啟動，終端機會印每次 LLM 的原始回傳、以及操作/查證的內部過程。環境變數是 `DORO_WEB_DEBUG=1`。
- **doro 專屬瀏覽器設定檔**：放在系統 AppData 底下的 `web_profile`，**跟你平常的 Chrome 分開**；登入狀態存這。有怪狀況可整個刪掉重來。

---

## 怎麼啟動

- 平常用：雙擊 **`run_doro.bat`**
- 要看除錯：雙擊 **`run_doro_debug.bat`**
- 第一次會自動建 venv、裝相依、下載瀏覽器核心（要幾分鐘）；之後很快。
- 需要 Playwright：`pip install playwright` + `playwright install chromium`（bat 會自動裝）。

---

## 已知限制（務實面）

- **Google 帳戶登入**：Google 會擋「被程式控制的瀏覽器」，**過不了**——Google 相關的事請在你自己的正常 Chrome 做。（我不會去繞過偵測，那是禁止的。）
- **蝦皮 / FB / IG / 銀行**這類強防機器人的站：可能跳驗證/登入牆；先用「登入助手」登入一次會好些，但不保證每次都順。
- **準不準吃模型**：判斷走哪條、操作步驟、查證比對，都吃 AI 能力；線上模型（Gemini/GPT）比本地穩。
- **定位**：把 doro 當「會試、卡住會誠實跟你說、需要你時交回給你」的助手，不是「保證把事情做完」的機器人。公開、免登入的網站最順。

## 檔案地圖（這次新增／修改）

**新增（`doro_app/core/web/`）**
- `intent.py`：聽懂各種指令、抓 `[read:]/[operate:]/[verify:]/[login:]` 暗號。
- `reader.py`：`WebPageReader`（讀一次就關，主要給測試）。
- `session.py`：`WebSession` 持續開著的瀏覽器（開頁、快照、抓連結、執行動作、真Chrome+還原轉址）。
- `web_actions.py`：`[web:...]` 動作解析 + 送出類安全分級。
- `operator.py`：`WebOperator` 操作循環（看→想→問→做、防打轉、驗證/登入牆暫停續做）。
- `verify.py`：`VerifyPipeline` 查證管線（搜尋→抓來源→比對）。
- `runtime.py`：`WebRuntime` 專屬執行緒＋共用瀏覽器（讀/查證/操作都排隊走它、閒置自動關、確認橋接）。
- `worker.py`：舊的讀網頁背景worker（已不接線，保留）。

**新增（其他）**
- `run_doro.bat`、`run_doro_debug.bat`：venv 啟動器。
- `tests/core/web/`：對應測試。

**修改（重點）**
- `core/chat/orchestrator.py`：所有網頁路由與接線（攔 `[read:]/[operate:]/[verify:]/[login:]`、確認/停止、把結果丟回聊天）。
- `core/chat/chat.py`：LLM 原始回傳的除錯印出（`DORO_WEB_DEBUG`）。
- `core/chat/controller.py`、`settings.py`：max_tokens 開放到設定、per-request 覆寫。
- `core/chat/dia_prompt.txt`：教 AI 何時吐哪個暗號、桌面 vs 網頁的區分、誠實自檢。
- `utils/config_*.py`：`web_operation_enabled` 總開關設定。
- `ui/theme/themed_menu.py`、`ui/components/context_menu_controller.py`：右鍵選單的操作開關。
- `ui/dialogs/chat_settings_dialog.py`：Max tokens 欄位。
- `core/idle_behavior_manager.py`：網頁忙碌中閒置行為安靜。
- `app.py`：關閉時收掉瀏覽器；把 config 傳給 orchestrator。
- `pyproject.toml`：`web` 選用相依（playwright）。

## 定案的設計決定（為什麼這樣做）

- **合併一個瀏覽器**：讀＋操作＋查證共用一個持續開著的瀏覽器、一條專屬執行緒（Playwright 綁執行緒），一次只做一件。
- **操作要總開關 + 明講/確認**：操作最有威力，預設關、送出前確認。
- **查證獨立成管線**：因為查證要「多來源一起比對」，逐步操作做不好，所以搜尋→抓來源→一次比對。
- **路由交給 LLM**：桌面點擊 vs 網頁操作 vs 查證，語意重疊，關鍵字分不清，改由 AI 判斷。
- **不繞過機器人偵測 / 不代解驗證碼**：安全底線；改成誠實回報 + 交回給你。
