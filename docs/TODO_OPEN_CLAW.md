## 四根柱子（依「活靈活現 / 投入」CP 值）

### ② 持久記憶（檔案式）
- OpenClaw：`MEMORY.md` + 每日 log，純 Markdown/YAML，跨 session 記得使用者。
- Doro 現況：透過 `/記住` 或「任務與記憶說明」明確保存資訊，SQLite 跨重啟保留；可查看與忘記，啟用任務助理後組入聊天及任務上下文。心跳日誌仍獨立。
- 後續：有來源與可刪除的每日摘要、相關記憶檢索。純本機保存仍涉及隱私，尤其內容會送往設定的模型；不自動記錄所有對話。
- 為什麼重要：體感升級大、風險低，① 也要靠它記中間結果。
- 要一併決定：心跳日誌（目前只記 Doro 自己說過的話）要併入記憶還是保留。

### ① 真正的 agent 迴圈（多步）
- OpenClaw：模型 → 執行工具 → 結果餵回 → 重複到任務完成。
- Doro 現況：普通聊天讀頁基本單輪，`_auto_read_used` 一輪只自動讀一次；網站 `WebOperator` 已有獨立多步迴圈。
- 2026-10-12：網站迴圈擴充表單選擇、勾選、懸停、等待與分頁操作，補上目標重查和連續失敗停止；規劃與驗收見 [自動操作計畫](automation-plan.md)。這不等於跨搜尋／讀頁／桌面工具的通用 agent 迴圈已完成，後者仍待實作。
- 要做：在 Python 裡寫受控的多步迴圈，跑在**既有執行器 + 安全閘**之上
  （web operator / pynput / 狀態 / 移動）。
- 2026-10-13：新增 TaskRunner、工具表、SQLite 任務狀態、明確接續與逐步紀錄；可串接工作目錄檔案、可選隔離指令、搜尋／讀頁及網站操作。拒絕即停止，重啟不自動重播。跨桌面、MCP 及排程仍待實作。
- ⚠️ 代價：能讀網頁 / 點擊的多步迴圈一樣會被 prompt injection 打到。
  **安全閘要跟迴圈一起長，不能事後補。** 守門的是自家 code，改得動、測得到。

### ③ 自主心跳 v2：醒來會自己去看網站與分頁
v1（定時開口判斷、心跳清單、心跳日誌、待機只動不說）已完成，紀錄見 [heartbeat-plan.md](heartbeat-plan.md)、[ADR 0006](adr/0006-timed-heartbeat.md)。
v2 規格已於 2026-10-12 grill 定案，尚未實作：

- **能看什麼**：① 心跳清單裡列出的網站有沒有更新；② 使用者正在分享的分頁全文。暫不開放搜尋。
- **安全**：讀什麼由程式決定，模型只負責判斷；回覆仍用沒有 `tool` 欄位的 `HeartbeatReply`，讀到的內容再怎麼誘導，也只能說話、換姿勢、走路。不使用任何登入資料。
- **網站清單即白名單**：心跳清單新增區塊 `## 幫我看的網站`，一行一個網址（可附備註），最多 5 個。只讀列出的網址，不跟隨頁面連結，模型無法新增網址。
- **讀取方式**：單純 HTTP 下載網頁文字（不開瀏覽器、不跳視窗、不帶 cookie）；需要 JavaScript 才有內容的網站讀不到。
- **判斷更新**：每次心跳讀一次，與上次存下的內容逐行比對，只把新出現的行交給模型（每站最多 1500 字）；沒變就不送，省字數。
- **第一次**：只存下內容當基準、不通知，下一次起才算更新。
- **失敗**：讀不到就安靜略過並記 log；同站連續失敗 3 次，在下一次手動心跳時提醒一次。
- **分頁全文**：分頁分享開著且是目前頁時，附前 1500 字，並附分頁陪伴最近一次說的話，請模型別重複；換頁後過時結果照舊作廢。
- **沿用 v1**：跳過規則（安靜、忙碌、剛互動、人不在）、等泡泡、過時失效都不變；人不在時不讀網站，回來後下一次心跳仍能比對出期間的更新。
- **驗收重點**：白名單外的網址讀不到；第一次不通知；沒變不呼叫模型或不附內容；網頁內含誘導文字時心跳仍只能說話；斷線不報錯。

### ④ 結構化人格 + 上下文組裝
- OpenClaw：每輪把 `SOUL.md`（她是誰）/ `TOOLS.md`（她會什麼）/ `MEMORY.md`（她記得什麼）
  組進上下文。
- Doro 現況：`dia_prompt.txt` / `companion.txt` 比較散。
- 要做：人格 / 能力 / 記憶分檔、每輪穩定組裝進提示詞 → 人格一致。

## 建議起手順序
原建議為 ③→②→①→④；使用者明確要求擴大自動操作後，先完成 ②／① 的本機任務基礎，再做 ③ 心跳 v2、排程授權與 MCP，④ 另行整理。

## 心跳延後項目

心跳 v1／v2 刻意不做、留待之後各自 grill 的項目：

- **MCP 客戶端**：讓 Doro 連外部 MCP server（例如行事曆、信箱），心跳醒來可讀取。唯讀優先、要有核准與工具過濾；會碰到 ADR 0004 的安全牆，需另寫 ADR。與下方「Doro 當 MCP server」是相反方向。
- **定時提醒（cron）**：「下午 3 點提醒我喝水」這類精準時間觸發。v1 只靠心跳＋清單做到大致時段。
- **讀需要 JavaScript 的網站**：v2 讀不到時，改用隱形、乾淨（無登入資料）的瀏覽器重讀。
- **心跳上網搜尋**：搜尋結果來自任意網站，需另定白名單或只讀摘要。
- **心跳多步驟**：讓模型決定要不要讀下一頁，屬柱子 ①，要和安全閘一起設計。
- **執行腳本／指令**：明確使用者任務已接入可選 Docker 工具（ADR 0008），每次確認、無網路、只掛專用工作目錄；心跳仍不能執行指令。
- **回到電腦前打招呼**：系統閒置偵測到使用者回來時主動說一句，需防止短暫離開反覆觸發。
- **話量滑桿**：安靜／普通／話多三段，依設定改心跳任務說明。
- **心跳紀錄視窗**：列出每次心跳送出的內容與模型回覆，方便理解模型如何決定。v1 先寫進 log。

## 評估過並否決

- **讓 Doro 當外殼去限制 OpenClaw**（2026-10-12）：外殼只管得住經過它的工具；要真的限制，得關掉 OpenClaw 自己的執行、檔案、瀏覽器工具，只留 Doro 提供的。但 Doro 的工具 OpenClaw 本來就有，限制後等於多養一個 Node.js 大腦卻只做 Doro 已能做的事，失去使用它的意義。改走 Doro 自主路線（上方 ③ v2）。
