# 六項修正：實作計畫與驗收

起點：`fix/verify-skip-blocked-pages` 的 `6b69cc5`。此分支未包含先前對話聲稱寫好的 CONTEXT／ADR，亦未找到 domain-modeling skill 原文。
本次依使用者明確要求保持 CONTEXT 為語彙表、決策放 ADR；不聲稱符合未取得的 skill 全部格式。

## 1. 密碼欄位遮蔽

- 刪除快照對 input value 的取用，保留元件索引與可讀標籤。
- 密碼與一次性驗證碼只顯示用途；解析與 fill 前都防止模型代填。
- 操作歷史不寫入填寫內容，避免例外中的 Playwright call log 帶出值。
- 驗收：無標籤且已填密碼的真實 DOM 不出現在元件資料；填寫被拒且原值不變。

## 2. 取消與送出確認

- 使用狀態旗標，不把「檢查了幾次」當作取消時間。
- 模型返回、確認返回後再檢查，避免等待期間收到取消卻仍執行。
- 快照帶出 input_type／is_submit／focused，確認判斷採實際結構。
- 驗收：兩個等待點取消均沒有 execute；普通聊天頁 Enter、複合 Enter、空名稱按鈕、表單 Continue 會詢問；已聚焦搜尋框可搜尋。

## 3. 回覆與角色動作

- 共用角色表現入口，合法狀態清單提供給每條上網回答。
- 走路可見且說話等待到達；移動命令不授予 mouse／web 操作權限。
- 網頁摘要完成時先進角色入口，不能解析出新工具任務；失敗清掉本輪標記。
- 驗收：同一份帶狀態與移動的回答，在讀頁／查證／操作結果路徑都有一致表現；混入 mouse／operate／login 不執行。

## 4. 查證規格與測試同步

- 明確保留搜尋後開來源給使用者看的行為，最多前三個候選頁；單頁開啟或 snapshot 失敗仍繼續。
- 未讀到正文時使用搜尋摘要，無論長短均標記「可能只有摘要」，不把長摘要冒充正文。
- 更新六個舊規格斷言，新增失敗復原與角色／操作保護測試。
- 驗收：非手動測試全部通過；browser 測試使用隔離 Chromium、假資料，不需帳號或模型。

## 5. 分頁擴充

- Chromium MV3 擴充、配對設定頁、工具列連線標記、主文件只讀擷取。
- App 的分頁陪伴設定提供擴充 ID、埠、配對碼、分享開關、主動回應開關。
- WS 驗證 token＋Origin，斷線／模糊焦點／內部頁清除目前頁；同時核對 active＋visible＋focused。
- 驗收：真正載入擴充、收到目前頁、正文變更更新、背景頁不取代目前頁、暫停清除；錯誤配對 403。

## 6. 兩層活潑

- 現有基本陪伴繼續；新的頁面事件進入單一情境工作槽。
- 本機正規化去重，LLM 對同義內容可回 SILENT；忙碌期間只保留最新事件。
- 不设置發言冷卻或次數限額；模型失敗只降級，下一個事件可恢復。
- 換頁、開始使用者對話、停用後丟棄過時結果；角色正在走路時保留結果到動作完成。
- 驗收：重複不呼叫、忙碌只處理最新頁、旧答案不發言、模型失敗後可處理下一事件。

## 交付與實機驗收

見 `docs/web-presence-setup.md`。自動測試不代表使用者實際模型會每次正確選表情、辨識同義句，這部分需用實際設定試用。
任何需送出的網站行為仍由 Doro 的執行流程向使用者確認；不代登入或測試真實交易。
