## 目標與範圍

- 首次出現時位於 Doro 所在螢幕可用區域的水平中央，輸入列中心約在高度 78% 的位置；預設寬度維持 460 邏輯像素。
- 輸入列增加「＋／-」寬度按鈕，每次 40 像素，範圍 360–1200；實際顯示不超過目前螢幕工作區寬度。加寬／縮窄以輸入列中心為準，靠邊時移回可見範圍。
- 拖曳放開、點擊寬度按鈕後立即存檔。保存輸入列本身的位置與偏好寬度，不保存展開紀錄後整個視窗的左上角。關閉程式再開、隱藏再叫回都沿用最後的調整。
- 展開紀錄仍往上，空間不足時暫時避讓；收起時恢復原輸入列位置。這些版面操作不覆蓋使用者保存的位置。展開時主動拖曳／改寬則保存當時可見輸入列的位置。
- 讀取舊版設定時使用預設；損壞的寬度／位置各自回退，不清掉其他偏好。位置支援多螢幕負座標；原螢幕拔除或解析度縮小時，將視窗移回可用螢幕內。
- 本輪只調整聊天框幾何與保存，沿用現有聊天、隱藏、送出及錯誤回報行為。

## 實作與驗證

設定走 UIConfig／ConfigManager；FloatingChatWindow 處理按鈕、輸入列座標與螢幕邊界，ChatUIHelper 載入及保存。只在完成使用者調整時寫入，避免拖曳每一幀存檔。

驗證預設位置、寬度按鈕與邊界、展開時調整、暫時避讓不覆蓋設定、隱藏／重開、重新建立 app/helper 的保存還原、負座標與失效設定。離屏渲染預設／最窄／加寬後的輸入列與聊天紀錄，檢查控制項不重疊；跑相關及完整測試、Black／Ruff 與 repo 地圖檢查。推新分支並開獨立 PR，驗收紀錄接在本文件下方。
