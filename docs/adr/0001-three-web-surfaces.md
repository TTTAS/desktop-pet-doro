# ADR 0001：三個操作表面

- 狀態：採用
- 日期：2026-09-10

## 背景

「上網」「看這頁」「幫我點」原本可能指到不同瀏覽器或桌面目標，需要固定來源與權限邊界。

## 決策

| 語彙 | 實作入口 | 權限 |
| --- | --- | --- |
| 指令上網 | Playwright / WebRuntime | 讀、查證、經開關與確認允許的網站操作 |
| 存在感／你正在看的分頁 | Chromium 擴充 → 本機 WebSocket → PresenceController | 只讀目前 visible + focused 分頁；只輸出角色表現 |
| 桌面程式點擊 | UIA 元件資訊與現有桌面點擊流程 | 保留既有開關、白名單及取消限制 |

- 擴充沒有接收 click/type/goto 的執行入口。伺服器只回心跳。
- 明講「你剛開的頁」仍讀 Doro 的分頁。
- 啟用分頁分享後，未指定 Doro 分頁的「這頁」取擴充目前頁；沒有有效頁面就說明，不能偷偷換成 Doro 的頁。
- 未配對的舊使用者保留原本「這頁」指 Doro 分頁的行為；明講「我正在看的分頁」必須有分享來源。
- 網頁回答先經角色表現解析，不能再從內容觸發 read/login/operate/verify/mouse。

## 結果與限制

不同来源不再混用。瀏覽器失去焦點、切到內部頁、關閉或暫停分享會清掉目前頁。
因此把焦點移到 Doro 聊天視窗後，可能暫時沒有「正在看的分頁」可讀；不將先前快照假裝成當前頁。
