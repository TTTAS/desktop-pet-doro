# ADR 0007：擴充網站操作與快照綁定

- 狀態：採用
- 日期：2026-10-12
- 基準：ADR 0004、0005；計畫見 [automation-plan.md](../automation-plan.md)。

## 決策

1. 延伸既有 `WebStep → WebOperator → WebSession`，繼續在 WebRuntime 的專屬執行緒
   操作。新增 select、check、hover、wait、new_tab、switch_tab；不另建第二個 planner。
2. select 用完整選項 label，只支援原生單選；check 明確給 bool，支援 checkbox/radio，
   不以 toggle 猜狀態。兩者的 change handler 可能送出，均沿用聊天確認路徑。
3. 元件 metadata 和 DOM handle 在同次 JavaScript 評估中綁定；執行時不重新用
   CSS 編號找另一個元件。頁面、身分、名稱、型別、表單屬性或選項改變就拒絕，
   由下一輪重新觀察、重新確認。鍵盤焦點與其屬性也必須仍符合觀察。
4. 分頁 ID 綁實際 Page 物件、關閉後不重用；切分頁只能指定觀察所得的 ID。
   新分頁只接受沒有內嵌帳密的 http(s) URL；已有 12 個分頁時不再主動新增。
5. 維持 12 步總上限，加上連續三次執行錯誤停止；wait 最多 5 秒且計入步數。
   取消仍在模型返回後、確認後、下一步開始前檢查；確認橋接不得在取消競態下卡住。
6. 輸入值、textarea／contenteditable 草稿不進觀察；輸入文字保留原樣，空字串可清空。
   失敗回報不轉送可能包含輸入文字的 Playwright call log。
7. 分頁分享、心跳和普通讀頁的角色回覆仍沒有工具權限。網頁內容、元件名稱和結果
   都是資料，不是指令或授權；自動操作只能由使用者聊天的既有工具入口啟動。

## 取捨與限制

- 這是現有網站操作擴充；跨工具 agent、Windows 輸入、心跳 v2 和記憶各自有後續階段。
- 自訂元件、iframe、shadow DOM 尚無新的專用處理；選項和元件清單有長度上限。
- DOM 身分與可見屬性重查可攔截常見替換、導航、焦點變動，不能證明網站任意腳本
  沒有副作用，也不能消除瀏覽器收到單次操作後的競態。已發出的操作無法撤回。
- 成功判斷仍由模型依新觀察作答；受控假網站驗證不代表任意網站和模型的成功保證。
