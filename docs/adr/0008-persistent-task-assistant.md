# 0008：明確使用者任務、持久紀錄與隔離本機工具

狀態：採用。日期：2026-10-13。計畫：[agent-plan.md](../agent-plan.md)。

## 決策

效仿 OpenClaw 的任務迴圈及持久上下文，以 Python 內化進 Doro；不引入另一個 gateway。
`TaskRunner` 由工具表執行 `TaskDecision`，每輪最多 24 步（實例上限 48）、連續三次
工具錯誤即停止、每個持久任務最多 240 筆 intent。能力由程式註冊，模型不能新增工具。
第一次呼叫工具前須提供計畫；接續任務先執行唯讀工具，才准再次產生副作用。

只有直接使用者訊息可啟動：聊天 `tool.kind=task` 或 `/任務 目標`，而且任務助理
開關須啟用。路由模型不能重寫原始使用者目標。auto 回覆不派工具；頁面回答、
分頁陪伴與心跳仍只使用角色回覆 schema。這不是讓 `_auto_read_used` 失效的捷徑。

沿用 `WebRuntime` 序列工作佇列，任務、讀頁及網站操作互斥。工作執行緒不能存取
Qt 設定；目標模型、網站開關與搜尋 provider 在 GUI 執行緒凍結。GUI 透過 queued
signals 收到進度、確認、完成；退出時取消並給工作執行緒最多 30 秒清理。

## 工具與確認

- `file.list/read/write` 只處理專用 `agent/workspace`，拒絕絕對路徑、`..`、符號連結、
  junction、硬連結及特殊檔案；UTF-8 讀檔最多 64 KiB，模型最多收到 5500 字。
  寫入最多 6000 字，差異預覽不得超過 12000 字；確認後重查原內容再原子替換。
- `command.run` 使用使用者本機 Docker 的 `python:3.12-slim`，`--pull=never`，
  完整 argv 先確認。無網路、非 root、唯讀根、只掛載工作目錄、drop capabilities、
  no-new-privileges、256 MiB 記憶體、1 CPU、64 PIDs、32 MiB tmpfs；每次最多 60 秒，
  輸出超過 1 MiB 終止，送模型的輸出最多 5500 字。
  遠端 Docker context、沒有 Docker 或缺少映像時拒絕，沒有主機 shell fallback。
- `web.read/search` 可接入唯讀內容；只有另行啟用網站操作時才註冊 `web.operate`，
  沿用 WebOperator 確認及目標重查。子任務停止後會提供實際頁面觀察，停止不等於成功。
- 拒絕或逾時確認會停止整個任務。取消在模型返回後、確認後、執行前檢查；指令取消
  要移除容器，不能只殺 Docker CLI。清理無法確認時停止並留下容器名稱供檢查。

## 持久狀態與記憶

`agent/tasks.sqlite3` 與工具工作目錄分開。每次執行前存 intent，之後保存結果；
重啟時 queued/running/waiting 轉為 interrupted。使用者必須明確接續，不重播 pending
副作用。進度紀錄含工具參數與輸出，以便稽核；此資料會送往設定的模型，不等於沒有隱私風險。

任務上限 200 筆、記憶上限 100 則，每則 500 字；達上限請使用者自行清理，不暗自刪掉。
記憶只能由 UI「記住」或 `/記住` 建立，沒有模型寫記憶工具，也不自動保存所有聊天。
啟用時聊天及任務組入最近最多 6000 字的完整記憶；工具歷史最多最近 12 筆。
忘記、刪除任務及清除聊天分別處理，不刪工作目錄產出。SQLite 啟用 secure_delete，
不承諾清除外部備份、模型服務紀錄或其他已存在的副本。

## 邊界

Docker 安裝和映像由使用者管理。容器不是虛擬機，也沒有工作目錄磁碟配額；程式可
修改整個專用工作目錄。不要放入無關或不願交給模型的資料。路徑檢查不是抵抗同帳號
惡意主機程式競態的 OS 沙箱；此版以單一 Doro 實例與專用工作目錄為前提。
已完成的副作用不能靠取消撤銷。模型的任務完成率仍須真實使用驗收，測試不代表任何
模型都能完成任意目標。

排程授權、MCP 憑證／工具管理、心跳 v2、Windows UIA 擴充及人格分檔仍獨立規劃。
